## About Me

I'm a **Computer Science & Engineering** undergraduate at **Green University of Bangladesh** and a **full-stack developer** who likes owning a product end to end — database schema, API design, model inference, and the interface people actually use.

My work sits between **web engineering** and **applied AI**. I've built and deployed an image-based animal disease screening system that combines a custom CNN with a FastAPI inference service, a production e-commerce platform running on Django and PostgreSQL, and a distributed socket framework with load balancing and failover. Alongside that, I've shipped several client-side web applications with plain HTML, CSS, and JavaScript.

I'm currently deepening my backend and security fundamentals, and I'm looking for a **software engineering internship or junior role** where I can contribute to real production systems and grow into a professional engineer.

- **Working style:** documented code, reproducible local setup, honest scope
- **Interests:** open-source contribution, clean APIs, model optimization

## Featured Projects

### Animal Disease Detection System
End-to-end AI system for early disease screening in farm animals. A custom CNN classifies five species — cow, goat, sheep, buffalo, and chicken — while a separate human-vs-animal gate blocks misuse. Firebase handles authentication; FastAPI serves model inference.

`React` · `Vite` · `FastAPI` · `TensorFlow / Keras` · `Firebase`

[Live Demo](https://domestic-animal-disease-detection.onrender.com) · [Source Code](https://github.com/ruhulcsee/Domestic-Animal-disease-detection)

### Daily Dairy Shop — Django E-Commerce
Deployed dairy e-commerce platform with a custom admin dashboard for inventory, orders, and categories. Session-based cart, Cloudinary-hosted product images, a responsive Bootstrap storefront, and a PostgreSQL backend.

`Django` · `Python` · `PostgreSQL` · `Bootstrap` · `Cloudinary`

[Live Demo](https://dairyshop-bd.onrender.com)

### Travel.com — Tour Booking Platform
Multi-page tour booking site built without frameworks to keep the HTML/CSS fundamentals sharp. Destination galleries, package detail pages, booking and contact forms, and a responsive mobile-first layout.

`HTML5` · `CSS3` · `JavaScript` · `PHP`

[Live Demo](https://ruhulcsee.github.io/Tour/index.html) · [Source Code](https://github.com/ruhulcsee/Tour)

### SocketForge — Distributed Socket Framework
Client–gateway–worker system over raw TCP sockets. Thread-safe worker registry, round-robin load balancing, heartbeat-based failure detection, automatic failover, and a real-time React monitoring dashboard.

`Java` · `TCP Sockets` · `Multithreading` · `React`

[Source Code](https://github.com/ruhulcsee/project/tree/main/SocketForge)

### BD SmartBank — Core Banking Simulator
Academic banking and payment simulator with JavaFX dashboards for customers, banks, a central bank, and administrators. Backed by MySQL in production mode with an H2 fallback for demos.

`Java` · `JavaFX` · `MySQL` · `H2` · `Maven`

[Source Code](https://github.com/ruhulcsee/banking-mangement-project)

### CCN Campus Network Design
Multi-campus network design simulated in Cisco Packet Tracer — hierarchical topology, VLANs, RIP/OSPF routing, and subnetting, delivered with router/switch configuration files and a written project report.

`Cisco Packet Tracer` · `VLAN` · `RIP / OSPF` · `Subnetting`

[Source Code](https://github.com/ruhulcsee/CCN-Campus-Network-Design-Project)

## Research Interests

**Ongoing thesis:** *A Lightweight Deep Learning Framework for Real-Time Deepfake Image Detection on Social Platforms*

Deepfake imagery spreads quickly on social platforms and is often convincing enough to mislead people, damage reputations, and fuel misinformation. Most existing detectors are accurate but too heavy for fast, low-cost deployment. This research explores a lightweight framework that keeps detection accurate while reducing computational cost, targeting real-time inference on resource-constrained infrastructure.

- Computer Vision
- Deep Learning & CNNs
- Deepfake Detection
- Real-Time Inference
- Model Optimization
